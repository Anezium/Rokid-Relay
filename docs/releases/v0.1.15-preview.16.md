# Rokid Relay v0.1.15-preview.16

Release type: preview hotfix
Date: 2026-07-03

## Highlights

- Fixes the phone-side self-arm setup getting stuck on `Waiting for glasses link` after the ADB key/token were already available.
- Makes the Self-arm recovery row actionable: `Arm`, `Retry`, and `Re-arm` now start the self-arm provisioning path instead of only reporting key state.
- Automatically retries self-arm provisioning when the phone app opens and Relay is already enabled, provided Hi Rokid authorization exists, self-arm is not provisioned, and disable is not pending.
- Uses a dedicated self-arm foreground-start reason so recovery provisioning can open the CXR/glasses link independently of normal speech setup blockers.
- Clears stale pending self-arm authorization actions when Hi Rokid authorization cannot be launched or another auth request is already in flight.
- Allows the first automatic self-arm retry immediately, then throttles later retries.

## Test Focus

- Upgrade from `v0.1.15-preview.15`, open the phone app, and confirm a stuck `Waiting for glasses link` state progresses once the glasses are connected.

- Confirm a provisioned state still shows `Recovery armed` and the row can be used to re-arm/redeploy recovery.
