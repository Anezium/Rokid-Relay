# Rokid Relay v0.1.15-preview.6

Release type: preview
Date: 2026-06-21

## Highlights

- Fixes Android CXR speech discovery by declaring Android's speech recognition service query in the phone manifest.
- Prevents false-ready Android CXR setup states: Android 13+ is required, microphone permission must be granted, and Android 14+ requires the Companion link for background voice replies.
- Keeps the BLE wake reply notification ID on the phone so voice capture can start after CXR-L finishes waking, even if the glasses-side reconnect takes longer than expected.
- Gives just-woken CXR audio more time to deliver the first PCM bytes before reporting `Glasses audio stream unavailable`.
- Sets the glasses helper wake-reply wait window to 20 seconds for slower CXR-L reconnects without leaving the user waiting too long.

## Test Focus

- On Android 14+, leave `Companion link` unlinked with `Android CXR` selected and confirm `Start` shows the setup blocker instead of arming.
- Link the glasses as a companion device, press `Start`, send a replyable notification, wait for Relay to sleep, then reply from the old glasses inbox entry.
- Confirm the phone wakes, CXR-L reconnects, and voice capture starts without requiring a second tap.
- If Android CXR fails, confirm the diagnostics panel shows `Mic foreground`, `CXR audio`, and `Voice error`.
- Regression-test an API speech engine to confirm the new Android CXR blockers do not block cloud STT setup.
