# Rokid Relay v0.1.15-preview.9

Release type: preview hotfix
Date: 2026-06-28

## Highlights

- Improves `Android CXR` recognition on phones where the default speech recognizer mishandles injected CXR audio.
- Prefers the Google Android speech recognition service for segmented `EXTRA_AUDIO_SOURCE` sessions, then falls back to on-device/system recognizers.
- Ends segmented CXR input by closing the audio pipe only, instead of also calling `stopListening()`, so recognizers have a cleaner finalization path.
- Restores the final-result safety timeout to 2.5 seconds after logs showed the 8-second fallback added about eight seconds of avoidable delay.
- Keeps the glasses microphone as the only audio source for Android CXR replies.

## Timing Note

The phrase close path is back to roughly 2.5 seconds of silence after detected speech, plus at most 2.5 seconds waiting for Android's final result. This replaces the previous preview.8 follow-up build behavior that could wait about 8 seconds after the CXR pipe closed.

## Test Focus

- Select `Android CXR`, start a reply from the glasses, say a short French reply, and stop speaking.
- Confirm the HUD moves from `Listening`/`Recognizing` to review or failure without the extra eight-second wait.
- Confirm diagnostics show increasing `CXR audio` bytes during capture.
- If Android still reports no match, confirm the failure is prompt enough to retry.
- Regression-test one API speech engine to confirm cloud STT remains unaffected.
