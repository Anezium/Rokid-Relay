# Rokid Relay v0.1.15-preview.12

Release type: preview hotfix
Date: 2026-06-30

## Highlights

- Fixes Android CXR `Auto` so it no longer sends the phone locale as an explicit Android `SpeechRecognizer` language hint.
- Keeps Android CXR language selection locked to `Auto`; this is intentional because explicit Android language tags can still fail with injected CXR audio.
- Prevents background notification wakes from installing/updating the bundled glasses helper, avoiding Android disabling the glasses Accessibility service after a package update.

## Test Focus

- Select `Android CXR` and confirm only `Auto` is selectable in the language grid.
- Start a glasses voice reply and confirm `Speech language not supported` no longer appears for Android CXR Auto.
- Wait for the phone relay to sleep/wake on notifications and confirm the glasses Accessibility service stays enabled.
- If the helper needs an update, start Relay from the phone app foreground, then re-enable `Rokid Relay overlay` on the glasses if Android disabled it during that explicit update.
