# Rokid Relay v0.1.15-preview.7

Release type: preview
Date: 2026-06-22

## Highlights

- Fixes the recurring Android CXR wake-reply failure that surfaced as `Open phone app for Android CXR mic`.
- Forces Android speech recognition to consume the CXR glasses microphone pipe with `EXTRA_AUDIO_SOURCE` in segmented-session mode.
- Stops treating Android CXR as a phone microphone foreground-service capture path; Relay still requires Android speech permission, but the audio source remains the CXR PCM stream.
- Updates diagnostics and setup copy so `CXR audio` is the health signal for the glasses microphone pipe.

## Test Focus

- Select `Android CXR`, arm Relay, let the phone service sleep, then start a reply from the glasses inbox.
- Confirm the phone wakes, CXR-L reconnects, and voice capture reaches `listening` without the `Open phone app for Android CXR mic` error.
- Confirm diagnostics show increasing `CXR audio` bytes while speaking through the glasses.
- Regression-test one API speech engine to confirm cloud STT still uses the same CXR audio path.
