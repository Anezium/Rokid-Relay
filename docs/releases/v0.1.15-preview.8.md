# Rokid Relay v0.1.15-preview.8

Release type: preview hotfix
Date: 2026-06-23

## Highlights

- Fixes the `Microphone permission denied` regression from `v0.1.15-preview.7`.
- Restores Android CXR's microphone foreground-service type while voice recognition is active.
- Keeps the `EXTRA_AUDIO_SOURCE` segmented-session pipe so supported Android recognizers can consume the CXR glasses microphone PCM.
- Uses a clearer failure message when Android blocks background recognition: open the phone app for Android CXR, or use an API speech engine for background replies.

## Battery Note

This does not add a new keepalive or extend the relay awake window. The microphone foreground-service type is requested only while an Android CXR voice capture is active, then released after recognition, cancel, error, or review.

## Test Focus

- Select `Android CXR`, arm Relay, let the phone service sleep, then start a reply from the glasses inbox.
- Confirm the phone no longer reports `Microphone permission denied`.
- If Android blocks background recognition, confirm the glasses show the clearer Android CXR phone-open message.
- While voice capture is active, confirm diagnostics show `Mic foreground: active` and increasing `CXR audio` bytes.
- Regression-test one API speech engine to confirm cloud STT remains unaffected.
