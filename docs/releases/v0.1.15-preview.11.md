# Rokid Relay v0.1.15-preview.11

Release type: preview hotfix
Date: 2026-06-29

## Highlights

- Handles Android CXR `SpeechRecognizer` error 11 as a transient recognizer-service disconnect.
- Retries one Android CXR recognizer session after that disconnect instead of immediately showing `Speech recognition error 11`.
- Preserves a recognized partial transcript when Android disconnects after speech has already been heard.
- Keeps the glasses setup screen's Accessibility status refreshed while the screen is open.

## Test Focus

- Select `Android CXR`, start a glasses voice reply, and confirm a transient Android recognizer disconnect retries once before surfacing an error.
- If Android disconnects after partial text appears, confirm the partial can still enter the review countdown instead of being discarded.
- Leave the glasses setup screen open, toggle `Rokid Relay overlay` in Accessibility settings, and confirm the setup screen reflects the status after returning.
- Confirm the phone rebuild bundles glasses helper `0.1.10-preview.6`.
