# Rokid Relay v0.1.15-preview.15

Release type: preview hotfix
Date: 2026-07-03

## Highlights

- Removes the PC-copied-key requirement for self-arm recovery setup.
- Generates a per-install ADB recovery key inside the phone app private files.
- Provisions that key to the glasses helper over the existing phone/glasses command channel.
- Lets the glasses helper enable loopback ADB TCP and request trust for the generated public key during provisioning.
- Lets the Relay Accessibility service auto-accept the standard ADB authorization prompt only during enrollment, only from expected system prompt packages, and only when the prompt contains the generated key fingerprint.
- Rolls back failed first enrollment by disabling ADB TCP again instead of leaving recovery half-armed.
- Updates phone setup copy to `Key ready`, `Waiting for glasses link`, and `Recovery armed`.

## Test Focus

- Install the phone APK on a clean phone app data state and confirm the Self-arm row shows `Key ready`, not `No key`.
- Start/arm Relay from the phone and confirm the generated key is sent in `self_arm_provision`.
- With the Relay Accessibility service enabled on glasses, confirm first provisioning can authorize the generated ADB key and start the watchdog without copying a PC key.
- Force-stop the glasses package, remove the Relay Accessibility service from `enabled_accessibility_services`, open the glasses app, and confirm Accessibility plus watchdog recover.
