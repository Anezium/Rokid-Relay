# Rokid Relay v0.1.15-preview.19

Release type: preview fix
Date: 2026-07-05

## Highlights

- Fixes Cantonese transcription with the Android CXR (Google SpeechRecognizer) engine. The app previously sent only the `zh-HK` locale and, when the recognizer rejected it, retried once with no language hint — falling back to the phone's system language, which yields Mandarin/Simplified Chinese or a `Speech language not supported` error. Google's actual Cantonese recognition locale (`yue-Hant-HK`) was never attempted.
- The Cantonese language setting now walks an ordered chain of recognizer locales, trying each for real and moving on when the phone rejects it: `yue-Hant-HK` → `yue-HK` → `zh-HK` → no hint (Auto). The first accepted locale wins, so phones whose Google recognizer supports Cantonese transcribe in Cantonese with Traditional Chinese output.
- A transient recognizer error mid-session no longer resets the language choice: the retry keeps the locale that was in use instead of silently dropping back to the system language.
- Languages with a single recognizer locale behave exactly as before; Auto is unchanged.

## Background

On-device probing showed `checkRecognitionSupport()` cannot be used to pre-filter locales: it reports support even for an invalid control tag (see v0.1.15-preview.10). The only reliable strategy is to attempt `startListening` with each candidate and walk the chain on `ERROR_LANGUAGE_NOT_SUPPORTED` / `ERROR_LANGUAGE_UNAVAILABLE`, which is what this release implements.

## Test Focus

- On a phone whose Google recognizer supports Cantonese (typically online recognition, or the Cantonese offline pack installed): set Speech language to `廣東話` (Cantonese), use the Android CXR engine, and confirm a glasses voice reply transcribes in Cantonese with Traditional Chinese characters — not Simplified, not Mandarin.
- Watch logcat for the chain walk on phones that reject the first tags: `Android CXR rejected language 'yue-Hant-HK'; retrying with 'yue-HK'` and so on, ending with `retrying without language hint` only when every Cantonese locale is rejected.
- Confirm other languages (English, French, …) and Auto behave exactly as before.
