# Rokid Relay v0.1.15-preview.22

Release type: preview fix
Date: 2026-07-05

## Highlights

- Fixes the one-time Self-arm wireless-debugging bootstrap failing on glasses whose system language is not one of a handful of Latin-script locales. Reported by a Russian user: tapping **Bootstrap** opened the glasses' "About phone" screen and stalled there — no pairing code ever appeared.
- Root cause: the on-glasses setup automator navigated the Settings app by matching the **localized text** of each row (Build number, Wireless debugging, "Pair device with a pairing code", …). Those match-lists only covered English, French, Spanish, Portuguese, Italian and German. On a Russian device none of the rows matched, so the automator could never enable Developer options, never reached Wireless debugging, and gave up on the About-phone page.
- Fix, two layers:
  - The build-number row is now found the language-independent way first: by matching the device build fingerprint (`Build.DISPLAY` / `Build.ID`, e.g. `SKQ1.240613.001 release-keys`), which reads identically in every language. This alone lets the automator enable Developer options on any locale, including ones we have never seen.
  - Russian (Cyrillic) labels were added to every text-match and page-detection list as a second layer, and the text normalizer was reworked so non-Latin scripts are compared correctly instead of being silently stripped.
- Added JVM unit tests covering the Cyrillic labels, hyphen/`Wi-Fi` spelling variants, Latin accent-folding, and the build-fingerprint match.

## Verification

- Glasses-module unit tests pass; both APKs build.
- Exercised end-to-end on the reference glasses + phone, from a first-time state (glasses `WRITE_SECURE_SETTINGS` revoked, Developer options and Wireless debugging off), **twice**:
  - Glasses in English — confirms the Developer-options recovery and the build-fingerprint fallback.
  - **Glasses in Russian (Русский)** — the actual reported configuration. The automator drove the real Cyrillic Settings menus (Номер сборки → Отладка по Wi-Fi → Подключение устройства с помощью кода подключения), read the 6-digit pairing code, the phone completed pairing, and the glasses ended with `WRITE_SECURE_SETTINGS` granted. This is the exact path that used to dead-end on the About-phone screen.

## Test Focus

- Any non-Latin system language on the glasses (Russian first): tap **Bootstrap** on the Self-arm recovery row with the phone and glasses on the same Wi-Fi, and confirm the setup reaches "bootstrap complete" without stopping on the About-phone or Developer-options screen.
- Latin languages already covered before (English/French/…): confirm the bootstrap still completes as it did in preview.18.
