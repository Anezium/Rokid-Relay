# Rokid Relay v0.1.15-preview.21

Release type: preview fix
Date: 2026-07-05

## Highlights

- Fixes voice replies that ended in `Android STT returned no text from CXR audio` even though the glasses microphone was clearly picking up speech. Reported on a Hong Kong OPPO doing Cantonese right after preview.20 fixed the `Speech language not supported` error there.
- Root cause: since v0.1.15-preview.7 every recognition session requested Android's *segmented session* mode, but in that mode the recognizer delivers final text through the `onSegmentResults` / `onEndOfSegmentedSession` callbacks — which the app never implemented. Sessions only produced text when the recognizer happened to stream partial results; on recognizers that emit none (Google's online recognizer doing Cantonese, for example), the final text was silently dropped and the session timed out empty. The on-screen speech diagnostic never showed the problem because it does not use segmented mode.
- The system-default recognizer is now driven exactly the way the last known-good versions (v0.1.7 and earlier) drove it: a plain non-segmented session with an explicit end-of-input signal when the glasses stop sending audio. Final text arrives through the ordinary `onResults` callback again.
- The fallback recognizers (other Google services, on-device) still use segmented mode, and the app now implements the segmented callbacks properly: each finalized segment is accumulated and shown as it arrives, and the session completes with the accumulated text. The recognition timeout and error-recovery paths also pick up segment text now, so a segmented session can no longer end empty while text was received.
- Each recognition attempt now logs whether segmented mode is on (`Android CXR recognizer attempt target=… tag=… segmented=…`) so reports show the exact configuration that handled a session.

## Verification

- Static review of the recognizer flow against the v0.1.7 sources (the last release the reporting user confirmed working) — the default-recognizer path now matches it: system-default service, no segmented session, `stopListening()` on pipe close.
- Phone module unit tests pass and the APK builds. Not yet exercised on-device; this preview exists to confirm the fix on the reporting user's OPPO.

## Test Focus

- Cantonese on the Android CXR engine: send a glasses voice reply in Cantonese — expect the transcription to come back instead of `Android STT returned no text from CXR audio`.
- Any language: confirm voice replies still transcribe from the glasses mic and that partial text still appears live on the glasses while speaking.
