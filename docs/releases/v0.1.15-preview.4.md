# Rokid Relay v0.1.15-preview.4

Release type: preview
Date: 2026-06-20

## Highlights

- Fixes the real old-inbox reply case after the wake-on-notification idle window.
- If the phone still has pending replyable inbox entries, Relay keeps CXR-L awake instead of sleeping after two minutes.
- Old glasses inbox entries can therefore still send `start_voice` to the phone and reply while the original notification remains active.
- If the pending inbox is empty, Relay still sends `phone_sleeping`, disconnects CXR-L, and waits for the next replyable notification.
- The glasses helper keeps the inbox visible and still fails cleanly if the phone link is genuinely unavailable.

## Test Focus

- Install the phone APK and updated glasses helper, open Rokid Relay, press `Start`, then close the app.
- Send a replyable notification and confirm it appears on the glasses and remains in the inbox.
- Wait longer than the original two-minute idle window.
- Open the old inbox entry and start a voice reply. The phone should still receive the command and start capture.
- Send or cancel the reply, then remove/clear the pending notification and confirm Relay can sleep again.
- Repeat the battery test with Relay armed and no pending inbox entries; CXR-L should sleep when there is nothing replyable.
