## Missing Hooks

- Keep POST_TEST_NOTIFICATION as a debug-only QA hook; release builds should use in-app diagnostics instead of exported ADB broadcasts.
- Keep the image-preview extras on POST_TEST_NOTIFICATION debug-only; they should enable the opt-in setting only for deliberate smoke tests.
- Implement DUMP_STATE as one-line JSON in logcat or a pullable app-private file.
- Expose an input-trace recorder/replayer so real touchpad event sequences become unit fixtures.
- Add SEND_FAKE_CXR_MESSAGE to exercise protocol reducers without live CXR service.
- Expose bundled helper version/fingerprint and last-installed helper version in DUMP_STATE.
- Add fake voice-state/audio hooks for no-first-byte, silence, cancel, VAD end, and timeout.
